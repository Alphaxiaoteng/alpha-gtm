# AgentPush 产品需求文档（PRD）

**版本：** v1.0  
**产品形态：** macOS / Windows 桌面应用  
**定位：** 本地优先的多平台内容管理、AI 浏览器自动化与发布系统。

## 1. 产品目标

AgentPush 让内容团队从本地素材库选择图文、视频、封面和 Markdown 文稿，通过账号隔离的浏览器 Profile、AI Agent 与受控发布任务，实现多账号、多平台和批量发布。

### 核心目标

- 统一管理本地内容、素材、平台版本、账号和发布任务
- 官方 API 可用时优先使用 API；能力不足时使用 BrowserOS/CDP 浏览器自动化
- 每个账号独立 Browser Profile、登录态、下载目录与任务锁
- 所有发布动作具备预检、审批、日志、截图、失败恢复和人工接管
- 默认本地保存素材、内容、账号元数据和执行记录

### 非目标

- 不提供 MCP Server 或第三方 Agent 平台接入
- 不托管用户 Cookie、密码或平台账号
- 不提供验证码破解、MFA 绕过、封禁规避或反检测对抗功能
- 不做通用 AI Browser 产品
- 不提供后台定时器或到点唤醒；任务只由用户或 Agent 当次明确发起，内容库排期可在该次准备中填写到平台原生时间控件

## 2. 用户与场景

| 用户 | 场景 | 价值 |
|---|---|---|
| 内容创作者 | 一条视频发多个平台 | 降低重复上传与填写成本 |
| 品牌矩阵运营 | 多账号、国内外分发 | 账号隔离与独立内容版本 |
| 电商运营 | 商品短视频批量分发 | 素材库、队列、批量发布 |
| 内容工作室 | AI 批量生产后分发 | 文件监听、适配和审核闭环 |

## 4. 功能需求

### 4.1 内容中心

- 导入并索引本地视频、图片、封面、音频、字幕、Markdown、DOCX
- 指定本地素材根目录，支持手动导入和目录监听
- 使用 SHA-256 去重，记录素材引用关系
- 自动读取时长、尺寸、帧率、码率、音轨等媒体元数据
- Markdown 与富文本编辑、Mermaid、LaTex、表格及版本历史
- 支持中英文等多语言内容版本
- 基于平台规则生成不同标题、描述、标签、封面及媒体变体

### 4.2 账号中心

- 一个账号绑定一个独立 Browser Profile 或 OAuth 凭据
- 支持品牌主号、地区号、产品号、客户号等账号分组
- 支持扫码/手动登录、OAuth 授权和会话健康检测
- 显示 Healthy、Warning、Login Required、Restricted、Disabled 状态
- 登录失效、平台限制或异常时通知用户并阻止后续自动提交

### 4.3 发布中心

- 支持立即、队列和批量发布
- 每个平台可配置独立账号、内容版本、素材和可见性
- 支持 API Only、Browser Only、API First、Draft Only、Review Before Submit、Trusted Auto Submit
- 支持任务重试、断点恢复、失败分类、任务取消和人工接管
- 保存最终帖文 URL、平台内容 ID、截图、日志和任务耗时

### 4.4 AI Agent

| Agent | 职责 | 输出 |
|---|---|---|
| ContentAgent | 生成、改写、翻译、标签和 CTA | 文案候选 |
| AdaptAgent | 按平台规则进行内容与媒体适配 | Platform Payload、转码计划 |
| PublishAgent | 调用 API 或操作浏览器完成发布 | 发布状态、URL、截图 |
| MonitorAgent | 检查登录态、任务异常、账号状态 | 告警和待处理项 |
| AnalyticsAgent | 采集指标、生成跨平台洞察 | 指标与优化建议 |

Agent 必须使用白名单工具、有限步骤、任务状态机和审批策略；验证码、MFA、平台异常或不确定提交场景必须进入人工接管。

### 4.5 数据分析

- 采集曝光、播放、阅读、点赞、评论、收藏、分享、涨粉、完播率等指标
- 支持内容、平台、账号、素材和时间维度分析
- 支持同一内容跨平台横向比较
- 生成发布成功率、失败原因、账号健康与 Adapter 稳定性报表

## 5. 发布流程

```text
本地素材导入 → 内容编辑 → AI 平台适配 → 发布预检 → 创建任务
→ 队列 → API 或 Browser/CDP 执行 → 审批/提交
→ 保存 URL、截图与日志 → 用户明确发起指标采集
```

## 6. 验收标准

- 可导入、编辑、版本化管理本地内容与媒体资产
- 可管理 10 个目标平台的多账号与独立 Profile
- 可创建可审计的多平台发布任务并按策略执行
- 任务支持队列、重试、恢复和人工接管
- 发布成功后保存 URL、截图、平台 ID 和结构化日志
- 登录态、API Token 和密钥不以明文写入数据库
- macOS 和 Windows 都可安装、更新和运行
