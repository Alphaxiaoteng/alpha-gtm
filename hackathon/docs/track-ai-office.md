# 另一赛道参考：AI+办公（上海新云传媒）

> 仅供了解同场评委偏好与赛制对齐，我方队伍 `AlphaGTM` 属于 **AI+GTM（浙江冠英）** 赛道，切勿跑偏赛道。

- **命题企业**：上海新云传媒（户外媒体运营商：近 5000 台公交车身、近 1000 个地铁口点位、近 10000 平米商圈媒体）
- **核心任务**：给定行业（5 选 1）与预算（100/200/500 万）及档期，基于红豆库存系统与大数据可视化平台，生成可交互的 HTML 投放方案。
- **同场可借鉴的评审/交付共性标准**（从 AI+办公赛题说明中提炼的组委会/评委视角）：
  1. **没有标准答案，敢于提出企业没想到的解法是高分项**。
  2. **强调「真数据+现场可交互演示」**：路演现场可访问、可交互，评委现场换输入（如换车型/换编码/换询盘）能当场出结果；预录视频、纯截图轮播不加分。
  3. **四件套思维**：可运行原型 + 源代码（Git + README） + 路演演示答辩 + 一页纸说明（团队分工、AI 能力清单、数据使用说明、已知局限）。
