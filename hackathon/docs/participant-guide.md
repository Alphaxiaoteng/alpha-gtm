## 三、作品提交要求（B1X 提交页）

> 重要：**全队成员均可编辑保存草稿，但只有「队长」可以点击正式「提交作品」或「撤回修改」。** 仅保存草稿或已撤回不会进入评审！

- **必填项（3 项）**：
  1. **作品标题**
  2. **作品简介**（上限 500 字）
  3. **代码仓库链接**（Git 仓库，可选择是否公开，建议附带清晰 README 与运行说明）
- **选填项**：
  1. **在线演示地址**
  2. **演示视频**：MP4 / MOV / WebM，单个不超过 1 GB（或填写可直接播放的视频链接）
  3. **封面图**：JPG / PNG / WebP，不超过 8 MB（用于作品广场卡片展示）
  4. **附件**：PDF / PPT / PPTX / ZIP，单个不超过 20 MB，最多 3 个（例如：一页纸说明、路演 PPT）
