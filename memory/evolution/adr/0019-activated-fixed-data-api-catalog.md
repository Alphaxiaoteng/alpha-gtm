# 0019. 数据 API 使用激活门与固定平台接口目录

| 字段 | 值 |
|------|-----|
| Status | accepted |
| Date | 2026-07-25 |
| Area | tikhub, ui, security, data |

## Context

趋势雷达需要逐步接入抖音、小红书、视频号、快手和公众号的搜索、榜单、内容、评论与博主数据。第三方接口会计费，API Key 不能回显，供应商“存在接口”也不能被展示成“应用已接入”。

用户希望先在设置页自行配置 TikHub，再基于已激活配置继续开发真实功能。文章平台不扩张，数据 API 目录只保留公众号。

## Decision

- 设置页只允许选择 TikHub 官方的中国大陆与全球域名，不接受任意 Base URL。
- API Key 仅保存到本机权限为 `0600` 的文件；配置响应、工具状态、日志与错误信息都不回显 Key。
- 保存 Key 后状态为“待测试”。用户明确确认并通过 TikHub 用户信息接口后才激活；替换 Key 会立即取消旧激活状态。
- 真实网络工具必须读取同一份已激活配置；未激活时拒绝请求。
- 接口目录固定为抖音、小红书、视频号、快手、公众号。每项能力分别标注“已接入”“本地分析”“待绑定”或“依赖前置接口”。
- 页面只列出已核对的固定路径；本地选题、对标与圈层不伪装成供应商端点。

## Consequences

### 正

- 用户知道哪项能力现在能用、哪项只是下一步开发目标。
- 凭证不会通过 GET 响应或供应商错误正文泄漏，替换凭证也不会继承旧测试结果。
- 后续接线可以复用同一激活门和本地快照边界，不需要新增凭证系统。

### 负 / 代价

- 用户必须先保存并主动测试，不能粘贴 Key 后立即静默抓取。
- 接口目录需要随 TikHub 官方路径变更人工核对；没有真实 Key 时只能验证配置契约，不能声称业务接口调用成功。
- 视频号、快手和公众号当前仍需逐项接线与真实响应夹具。

## Alternatives

| 方案 | 为何未选 |
|------|----------|
| 允许用户填写任意 API Base URL | 扩大凭证外发与 SSRF 风险，也无法维护固定接口契约 |
| 保存 Key 后自动联网测试 | 会在用户未确认时产生外部请求或计费 |
| 所有平台统一显示“已支持” | 混淆官方接口存在与应用已经接入，违反可验证状态边界 |
